# Gole Kaab - Comments & Posts Schema

This document outlines the database schema for the posts, comments, and interactions feature.

## 1. `posts` Table

This table stores the main posts or reports created by users.

| Column      | Type                        | Description                                                                 |
|-------------|-----------------------------|-----------------------------------------------------------------------------|
| `id`        | `uuid` (Primary Key)        | Unique identifier for the post. Defaults to `uuid_generate_v4()`.           |
| `created_at`| `timestamp with time zone`  | Timestamp of when the post was created. Defaults to `now()`.                |
| `user_id`   | `uuid` (Foreign Key to `auth.users.id`) | The user who created the post.                                  |
| `content`   | `text`                      | The main body of the post.                                                  |
| `tags`      | `text[]` (Array of text)    | An array of tags associated with the post. Can be nullable.                 |
| `status`    | `text`                      | Moderation status (e.g., 'published', 'pending_review', 'removed'). Defaults to 'published'. |

### SQL for `posts` table:
```sql
CREATE TABLE public.posts (
  id uuid NOT NULL DEFAULT uuid_generate_v4(),
  created_at timestamp with time zone NOT NULL DEFAULT now(),
  user_id uuid NOT NULL,
  content text NOT NULL,
  tags text[],
  status text NOT NULL DEFAULT 'published',
  CONSTRAINT posts_pkey PRIMARY KEY (id),
  CONSTRAINT posts_user_id_fkey FOREIGN KEY (user_id) REFERENCES auth.users (id) ON DELETE CASCADE
);
```

## 2. `comments` Table

This table stores comments made on posts.

| Column      | Type                        | Description                                                                 |
|-------------|-----------------------------|-----------------------------------------------------------------------------|
| `id`        | `uuid` (Primary Key)        | Unique identifier for the comment. Defaults to `uuid_generate_v4()`.          |
| `created_at`| `timestamp with time zone`  | Timestamp of when the comment was created. Defaults to `now()`.               |
| `user_id`   | `uuid` (Foreign Key to `auth.users.id`) | The user who created the comment.                                 |
| `post_id`   | `uuid` (Foreign Key to `public.posts.id`) | The post this comment belongs to.                               |
| `content`   | `text`                      | The main body of the comment.                                               |
| `status`    | `text`                      | Moderation status (e.g., 'published', 'pending_review', 'removed'). Defaults to 'published'. |

### SQL for `comments` table:
```sql
CREATE TABLE public.comments (
  id uuid NOT NULL DEFAULT uuid_generate_v4(),
  created_at timestamp with time zone NOT NULL DEFAULT now(),
  user_id uuid NOT NULL,
  post_id uuid NOT NULL,
  content text NOT NULL,
  status text NOT NULL DEFAULT 'published',
  CONSTRAINT comments_pkey PRIMARY KEY (id),
  CONSTRAINT comments_user_id_fkey FOREIGN KEY (user_id) REFERENCES auth.users (id) ON DELETE CASCADE,
  CONSTRAINT comments_post_id_fkey FOREIGN KEY (post_id) REFERENCES public.posts (id) ON DELETE CASCADE
);
```

## 3. `likes` Table

This table tracks likes on both posts and comments.

| Column      | Type                        | Description                                                                 |
|-------------|-----------------------------|-----------------------------------------------------------------------------|
| `id`        | `bigint` (Primary Key, Identity) | Unique identifier for the like.                                        |
| `created_at`| `timestamp with time zone`  | Timestamp of when the like was made. Defaults to `now()`.                   |
| `user_id`   | `uuid` (Foreign Key to `auth.users.id`) | The user who gave the like.                                     |
| `post_id`   | `uuid` (Foreign Key to `public.posts.id`) | The post that was liked. Null if it's a comment like.         |
| `comment_id`| `uuid` (Foreign Key to `public.comments.id`) | The comment that was liked. Null if it's a post like.      |

### SQL for `likes` table:
```sql
CREATE TABLE public.likes (
  id bigint GENERATED BY DEFAULT AS IDENTITY,
  created_at timestamp with time zone NOT NULL DEFAULT now(),
  user_id uuid NOT NULL,
  post_id uuid,
  comment_id uuid,
  CONSTRAINT likes_pkey PRIMARY KEY (id),
  CONSTRAINT likes_user_id_fkey FOREIGN KEY (user_id) REFERENCES auth.users (id) ON DELETE CASCADE,
  CONSTRAINT likes_post_id_fkey FOREIGN KEY (post_id) REFERENCES public.posts (id) ON DELETE CASCADE,
  CONSTRAINT likes_comment_id_fkey FOREIGN KEY (comment_id) REFERENCES public.comments (id) ON DELETE CASCADE,
  -- Ensure a like is for either a post or a comment, but not both
  CONSTRAINT chk_like_target CHECK ((post_id IS NOT NULL AND comment_id IS NULL) OR (post_id IS NULL AND comment_id IS NOT NULL)),
  -- Ensure a user can only like a post or comment once
  CONSTRAINT unique_post_like UNIQUE (user_id, post_id),
  CONSTRAINT unique_comment_like UNIQUE (user_id, comment_id)
);
```

By creating these tables, we can store and manage user-generated content and interactions effectively. The SQL provided can be run in the Supabase SQL Editor to set up the database.
